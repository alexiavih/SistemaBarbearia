# 💈 Sistema de Gestão para Barbearia

> Aplicação completa de gestão para barbearia composta por um **Módulo Web (JSP/Servlet)** unificado com tema escuro/dourado e um **Módulo Desktop (Java Swing)** para gestão interna.

---

## 📌 Sobre o Projeto

O **Sistema Barbearia** foi desenvolvido para simplificar e organizar o dia a dia de um estabelecimento, permitindo o controlo eficiente de produtos/serviços, clientes e agendamentos (relações).

O projeto é dividido em duas frentes:
1. **Módulo Web:** Interface moderna construída em Java EE (JSP/Servlets) utilizando Materialize CSS com um tema personalizado *Dark Gold* (`#121212` e `#d4af37`).
2. **Módulo Desktop:** Aplicação nativa em Java Swing para operações administrativas diretas.

## 🚀 Módulos da Aplicação

- **🛍️ Produtos / Serviços:** Cadastro, alteração, consulta e remoção de serviços prestados.
- **👤 Usuários:** Gestão de utilizadores e clientes com validações de dados.
- **📅 Relações (Agendamentos):** Vínculo direto entre utilizadores e os produtos/serviços selecionados.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK)
* **Tecnologias Web:** Java EE (JSP & Servlets), Apache Tomcat
* **Interface Desktop:** Java Swing
* **Base de Dados:** SQLite JDBC
* **Front-End:** Materialize CSS, Google Material Icons
* **Controlo de Versões:** Git e GitHub
